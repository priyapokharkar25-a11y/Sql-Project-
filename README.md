# Banking Management System – SQL Project

## Project Overview

The **Banking Management System** is a SQL-based database project developed using MySQL. The project focuses on managing banking operations such as customer details, bank accounts, transactions, branches, and loan information.

The main objective of this project is to understand and implement SQL concepts, database management, data manipulation, and data analysis through practical queries.

## Project Objectives

- Create and manage a banking database.
- Store and organize customer information.
- Manage bank accounts and account balances.
- Maintain transaction records.
- Manage branch and loan information.
- Establish relationships between tables using Primary Keys and Foreign Keys.
- Perform data analysis using SQL queries.

## Technologies Used

- **Database:** MySQL
- **SQL Concepts:** DDL, DML, DQL, Joins, Subqueries, Aggregate Functions, Window Functions
- **Tool:** MySQL Workbench

## Database Structure

The project uses the following five main tables:

| Table Name | Description |
|---|---|
| Customers | Stores customer details |
| Accounts | Stores account information and balances |
| Transactions | Stores deposit and withdrawal records |
| Branches | Stores bank branch details |
| Loans | Stores customer loan information |
