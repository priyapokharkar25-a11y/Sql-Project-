# Spotify Database Management System (SQL Project)

## Project Overview
This project focuses on creating and managing a Spotify database using SQL. It demonstrates how a music-streaming platform stores and manages information about users, artists, albums, songs, playlists, and listening history. The database is created using MySQL and is named `SpotifyDB`.

## Project Objectives
- To create and manage a relational database.
- To store information about Spotify users, artists, albums, and songs.
- To manage playlists and listening history.
- To practise SQL queries for retrieving and analysing data.
- To understand database relationships and SQL operations.

## Database Tables
The project contains six tables:
1. **Users** – Stores user information.
2. **Artists** – Stores artist details.
3. **Albums** – Stores album information.
4. **Songs** – Stores song details.
5. **Playlists** – Stores playlist information.
6. **ListeningHistory** – Stores users' listening activity.

## How to Run the Project
1. Install MySQL Server on your computer.
2. Open MySQL Workbench.
3. Connect to your MySQL server.
4. Open the `SpotifyDB.sql` file.
5. Execute the SQL script.
6. The database, tables, sample records, and queries will be created and executed.

## Learning Outcomes
Through this project, I gained practical knowledge of SQL queries, database creation, data management, joins, grouping, filtering, and data analysis. This project helped me understand how relational databases work using a real-world music-streaming example.

## Conclusion
The Spotify Database Management System is an educational SQL project designed to demonstrate database management and SQL query skills. It uses sample data and is not connected to Spotify's actual database or services.
